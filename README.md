# Orchidex

Orchidex is a Tauri + React + TypeScript workspace targeting web and desktop.
The frontend runs on Bun, Vite, Tailwind CSS v4, and ReactFlow.

## Development

Install dependencies:

```bash
bun install
```

Run the web app:

```bash
bun run dev
```

Run the desktop app:

```bash
bun tauri dev
```

Build the web target:

```bash
bun run build
```

Build the desktop target:

```bash
bun tauri build
```
